# 血洗いの池 〜残穢〜

学習院大学で開催されるお化け屋敷サイトの公開用ファイルです。

## 公開URL

https://gakushuin.github.io/horror2026/

## 現在の構成

- `index.html`：サイト本体
- `style.css`：残穢テーマのホラー演出
- `script.js`：導入画面、カウントダウン、スクロール演出、匿名コメント欄
- `assets/poster.svg`：キービジュアル
- `assets/path.svg`：霧の夜道ビジュアル
- `assets/hallway.svg`：廊下ビジュアル
- `assets/hand.svg`：水面の手ビジュアル
- `assets/lake.svg`：夜の池ビジュアル
- `.nojekyll`：GitHub Pages用

## 内容

テーマは「血洗いの池 〜残穢〜」のまま、大学編として作成しています。
導入画面、フルスクリーンヒーロー、ビジュアルギャラリー、ストーリー、開催情報、注意事項、匿名コメント欄を含みます。

## 編集箇所

開催日を変える場合は `script.js` の `EVENT_START` と `EVENT_END` を編集してください。
教室名や整理券情報は `index.html` の INFORMATION セクションを編集してください。
